# 点云 BA 与 TSDF 子图融合任务书

日期：2026-10-24。范围：Ubuntu-22.04 中的 `stereo_recon` 功能包。

## 目标

- 保持图像、IMU 和 MSCKF 原有输入与估计频率；在深度推理前选择建图候选帧。
- 保存活动关键帧的相机坐标深度、颜色、原始 VIO 位姿、优化位姿与时间戳。
- 在独立 CPU 工作线程中进行多帧点到平面 BA；优化后重新融合活动 TSDF 子图。
- 发布独立建图坐标系的地图、当前关键帧点云和优化轨迹，保留连续 VIO 输出。
- 提供可选磁盘关键帧归档及离线重建入口，便于后续精度评估。

## 算法与依赖决策

使用本机已安装的 Ceres 2.0。参考 BALM/BALM2 的多帧共享平面和点簇统计量，
采用显式平面参数的最小二乘 BA，通过 Schur 消元求解。该实现不是 BALM2 的
解析特征值 Hessian 求解器，不能直接继承论文的速度或统计一致性结论。

- 位姿：单位四元数与三维平移；平面：单位法向与有符号距离。
- 固定窗口首帧消除规范自由度；邻接关键帧的 VIO 相对运动提供保守正则。
- 自适应体素划分寻找跨帧平面；限制每帧每平面的样本量，过滤深度跳变。
- 将局部点的加权齐次二阶矩分解成四维残差，减少每次迭代的逐点计算。
- 深度误差使用视差误差的一阶传播估计；权重在一次关联/求解内固定。
- 鲁棒损失作用于帧—平面点簇；这与逐点鲁棒损失不同。
- 检查平面支撑帧数、法向分布、帧间连接、代价和位姿修正幅度；失败回退初值。
- 原始深度与 VIO 有相关性，正则为松耦合近似；BA 结果不回灌 MSCKF。

## 地图生命周期与并发

1. ROS 回调仅缓存输入；推理线程按时间戳找位姿并筛选关键帧。
2. 推理线程把关键帧提交给有界建图队列；建图线程负责 BA 和 TSDF。
3. 活动子图保存完整深度；窗口外、子图内帧保持已接受位姿。
4. 接受优化后，从保存的深度重建活动 TSDF，整批提交地图快照。
5. 子图达到帧数上限时，将 TSDF 提取表面压缩到有容量限制的冻结表面地图，
   释放其深度；保留少量重叠帧连接下一子图。冻结表面不参加后续位姿调整。
6. 如需以后全局 BA/重新融合冻结子图，必须开启磁盘归档。首版不实现 PGO。
7. 清空或时间倒退递增 generation，使在途推理、BA 和重建结果失效。
8. 地图与轨迹采用独立 map 坐标系；发布 map 到 VIO 参考系的当前修正，
   历史关键帧分别保存优化位姿，不能用单个刚体修正代替历史优化。

## 完成检查与后续精度评估

本轮执行代码审阅与编译；未获单独要求时不新增或运行测试。
不把成功编译当作运行精度验证。后续在同一数据上对比 VIO 固定位姿 TSDF 与
BA + TSDF：ATE/RPE、保留观测的几何一致性、平面厚度、处理时延、丢帧、内存。
平面厚度与训练内代价下降不能单独证明位姿更准确。

主要风险：双目深度的系统偏差和像素相关性、低纹理/动态场景、单平面退化、
错误平面关联、TSDF 重建开销、冻结子图之间的残留误差与归档磁盘占用。
